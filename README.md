# Guia Fotográfico de Árvores de Divinópolis-MG

Guia de campo para o censo da arborização viária (calçadas e canteiros centrais) de Divinópolis-MG: chave visual de identificação, tabela de 53 espécies, calendário de floração, morfologia foliar e protocolo do censo.

## Fotos

As fotos em `fotos_web/` vêm de observações de grau de pesquisa do [iNaturalist](https://www.inaturalist.org), sob licenças CC0, CC BY, CC BY-SA e CC BY-NC. A autoria e a licença de cada foto aparecem no guia ao ampliar a imagem. Fotos CC BY-NC não podem ser usadas para fins comerciais.
